# Lab 01: User Management

## Objective
Demonstrate basic Microsoft Entra ID  user administration and identity lifecycle management.

## Scenario

NorthStar Technology needs to provision a new employee account for Alex Employee, who has joined the IT department.

## Tasks
1. Create a user account
2. Configure the user's basic information
3. Assign appropriate group membership
4. Verify the account
5. Disable the account
6. Document the changes

## Skills Demonstrated

- Microsoft Entra ID
- User administration
- Identity lifecycle management
- Group membership
- Access management
- Account troubleshooting

## Environment

-Microsoft Entra ID
-Test tenant
-Fictional organization: NorthStar Technology

## Results

- Located the Alex Employee test account in Microsoft Entra ID.
- Verified that the account is enabled.
- Verified that the user type is Member.
- No account changes were made during verification.

## Verification Notes

The account is enabled and configured as a Member user. 
Additional checks, including group membership and access assignments, will be performed in subsequent steps.
